# Glossário

**Termos, Expressões e Acrónimos (TEA) organizados alfabeticamente.**

| **_TEA_** | **_Descrição_** |
| :--- | :--- |
| **ATCC** | Acrónimo usado para identificar um Colaborador da Empresa de Transporte Aéreo (*Air Transport Company Collaborator*). |
| **Atribuição (*Assignment*)** | Termo usado para expressar o mesmo que "voo". |
| **Certificação de Aeronave** | Termo usado para caracterizar a permissão que uma aeronave possui para voar de/para um aeroporto. |
| **Checklist** | Documento usado para garantir que todas as tarefas são concluídas para manter a aeronave segura e operacional. |
| **Código IATA** | Acrónimo da Associação Internacional de Transportes Aéreos (*International Air Transport Association*), é um identificador único de três letras atribuído a aeroportos e cidades. |
| **Diagrama Técnico** | Representação detalhada que mostra os vários componentes e sistemas de uma aeronave. |
| **Fabricante** | Empresa ou entidade que projeta, constrói, testa, vende e faz a manutenção de aeronaves ou motores de aeronaves. |
| **Frota** | Termo usado para caracterizar um grupo de aeronaves operadas por uma companhia. |
| **GeoJSON** | Formato standard aberto, baseado em JSON, para representar elementos geográficos simples e os seus atributos não espaciais. |
| **Notas de Conclusão** | Expressão usada para descrever um grupo de observações opcionais registadas após a conclusão de uma manutenção. |
| **Operador de *Backoffice*** | Profissional ou equipa responsável pela gestão das funções de apoio administrativo e operacional relacionadas com as operações das aeronaves. |
| **Peça de Manutenção** | Expressão usada para especificar um componente da aeronave que necessita de manutenção. |
| **Pista (*Runway*)** | Termo usado para caracterizar a via onde as aeronaves aterram e descolam. |
| **Rede** | Termo usado para caracterizar um grupo de rotas operadas. |
| **Representações Gráficas** | Diagramas e gráficos que ilustram vários aspetos de uma aeronave ou métricas do sistema. |
| **Rota** | Termo usado para especificar a ligação/voo estabelecida entre dois aeroportos. |
| **Supervisor de Manutenção**| Profissional que supervisiona um ou mais Técnicos de Manutenção. |
| **Template** | Ferramenta estruturada usada para garantir a correta inspeção, manutenção, revisão geral ou modificação dos sistemas da aeronave. |
| **Técnico de Manutenção** | Profissional que inspeciona, repara e faz a manutenção de aeronaves para garantir que estão seguras e operacionais. |
